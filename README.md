## 📦 Installation

### Requirements
- Python 3.6+
- `pip3`
- Linux / macOS / Windows (WSL recommended)

### Quick Install

```bash
# Step 1: Clone the repository
git clone https://github.com/ethicial/v10000-Feature-Comparison.git

# Step 2: Navigate to the project directory
cd v10000-Feature-Comparison

# Step 3: Install required dependencies
pip3 install -r requirements.txt
```

### requirements.txt

Make sure the following file exists in the project root:

```
requests>=2.25.0
urllib3>=1.26.0
dnspython>=2.0.0
python-whois>=0.7.0
beautifulsoup4>=4.9.0
twisted>=22.0.0
```

```bash
pip3 install dnspython python-whois beautifulsoup4 twisted
```
